# Правила работы над проектом

- Работать только в этой папке. Перед началом работы читать текущие файлы проекта.
- Делать только ту функцию, которую просит пользователь. Не менять лишнее и не ломать уже работающие функции.
- Использовать только обычные HTML, CSS и JavaScript. Не использовать npm, фреймворки и внешние ресурсы.
- Все данные пользователя должны оставаться в браузере. Ничего не отправлять в интернет.
- Делать интерфейс удобным: использовать понятные подписи; поля и кнопки должны быть высотой не меньше 44 px; обеспечить работу с клавиатуры и на телефоне.
- Показывать денежные суммы с пробелами между тысячами, например `15 000 ₸`.
- Пустые и неверные числа считать нулём. Никогда не показывать пользователю `NaN`.
- Не запускать Git и ничего не публиковать без прямой просьбы пользователя.
- После работы перечислять изменённые файлы и объяснять, как проверить результат.
